# Ferit Can Gonden Portfolio Website

Bu klasor, MBP 206 Final Projesi icin hazirlanmis portfolyo web sitesidir.

## Icerik
- index.html
- assets/style.css
- assets/script.js
- cv/Ferit_Can_Gonden_CV_TR.pdf
- cv/Ferit_Can_Gonden_CV_EN.pdf

## GitHub Pages ile yayinlama
1. GitHub'da yeni bir public repo olustur.
2. Bu klasordeki tum dosyalari repoya yukle.
3. Repository > Settings > Pages kismina gir.
4. Branch olarak `main`, folder olarak `/root` sec.
5. Save dedikten sonra GitHub sana site linkini verecek.

Not: Site yayinlandiktan sonra CV icindeki `https://feritgonden.github.io` adresini kendi gercek GitHub Pages adresinle guncellemen onerilir.
